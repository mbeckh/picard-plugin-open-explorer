# Monkey API

Interface API for using the [Monkey plugin](https://github.com/mbeckh/picard-plugin-monkey/) for [MusicBrainz Picard](https://picard.musicbrainz.org) in own plugins.

This repository does not contain a plugin by itself but instead includes code to be shared among plugins for dependency management of the Monkey plugin in Picard.

## Usage
Please see [Monkey plugin](https://github.com/mbeckh/picard-plugin-monkey/) for documentation, installation and example.
